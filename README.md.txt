# Digital Signature App using RSA

## Description
This project demonstrates how to:
- Generate RSA key pair
- Sign a document
- Verify a signature
- Detect tampering

## Steps
1. Run keygen.py
2. Run sign.py
3. Run verify.py

## Result
- Signature is valid for original file
- Signature fails if file is modified

## Technologies
- Python
- Cryptography Library
